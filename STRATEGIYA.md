# Ichki strategiya (saytda ko'rsatilmaydi)

Saytdagi har bir bo'lim quyidagi tahlildan kelib chiqqan. Bu fayl server tomonidan berilmaydi.

## SWOT — AB Media

| | |
|---|---|
| **Kuchli** | Boshidan oxirigacha bitta prodyuser; rejissyor + prodyuser; yirik brendlar (Uztelecom, Asaka Motors, Good Day); agentlik bilan ishlash formati (prodyuserlik nazorati); tarqatish bosqichi |
| **Zaif** | Kichik quvvat (oyiga ~3 loyiha); ochiq raqamli natijalar kam; shaxsiy brendga bog'liqlik; narxlar ochiq emas |
| **Imkoniyat** | Performance-reklama qimmatlashmoqda → brendlar ishonchga pul ajratishga tayyor; yangi brendlar bozorga kirmoqda; agentliklarga prodyuserlik nazorati kerak |
| **Xavf** | Arzon frilanser videograflar; ichki SMM jamoalar; AI-video; mijozlar faqat lid narxini o'lchaydi |

## Xulosalar → saytdagi qarorlar

1. **"Chiroyli video" emas, biznes natija sotiladi.** Xavf: mijoz faqat CPL o'lchaydi → sayt
   gapni CJM tiliga o'tkazadi: tanilish va ishonch bosqichlarida yo'qotilgan odamlar, va
   "xuddi shu byudjetda +N xaridor" hisobi (3D kolbalar + kalkulyator).
2. **Zaiflik → kuch.** Kichik quvvat "oyiga 3 tadan ortiq olmaymiz" deb sifat belgisi sifatida
   beriladi; "bo'sh joylar: 1" — shoshilinchlik.
3. **Natija o'lchanadi.** Raqobatchilarda yo'q: tarqatish bosqichi "Tarqatish va o'lchov"ga
   aylantirildi, FAQda brand-lift so'rovi tushuntiriladi — ishonch uchun.
4. **Kirish to'sig'i past.** Asosiy CTA — "Bepul CJM-audit" (sotuv emas, diagnostika),
   bonus — 2 ta qo'shimcha konsepsiya varianti.
5. **Isbot.** Har bir featured keysda ko'rish va natija raqami; logolar lentasi; keys oynasi.
